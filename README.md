  <li><h4>Purpose:</h4>This repository corresponds to an interactive quiz built as a recovery activity for the second unit (sets, relations and functions) of the Computación y Estructuras Discretas I course. It presents a grid of 22 numbered cards; each one opens a question about relations, invertibility, injective/surjective/bijective classification and function composition, and can be revealed to check the answer, rendered with KaTeX for proper mathematical notation. Each question has a 1-minute timer. Two more screens hold the oral-defense (sustentación) of the Deep Learning workshop of Computación y Estructuras Discretas III. The general screen has 40 questions common to every submission, grouped by topic (valid rows, data-quality audit, EDA, features and leakage, split and baseline, MLP, RNN/LSTM, metrics and architecture comparison). The specific screen shows, for the chosen student code, four ★ questions about that student's own decisions and AI-use log. Both use a 2-minute timer; the teacher picks the code and the question numbers with an external roulette.</li>
